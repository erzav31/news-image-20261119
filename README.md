Entry for make.fun competition `news-image-20261119`: "Sum up 19 November's world news in one image". A dark navy "night desk" poster (1024×1024) drawn with PIL: globe lead panel, a 3×2 grid of the day's stories, an "Also Today" strip, and a sources footer. No photos, no copyrighted images — every shape is drawn from scratch.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts   # writes out/entry.png
```

Node 22, standard library only. The program copies the bundled `entry.png` to `/output/entry.png` and verifies the copy is complete by comparing file sizes; it uses no network and writes identical bytes on every run.
